# Create a Project Charter
A 10,000 square meter commercial building in Accra, Ghana is proposed to meet the growing demand for commercial space.
It must comply with building codes, meet modern business needs, and stay within a $20M budget and 24-month time line.
Include plans for design and construction, procurement, quality checks, and building code compliance.
A project manager leads 20 team members. Key stakeholders include the client, government authorities, and the general public.

Create a detailed project charter.

Generate GitHub-Flavored Markdown suitable for VS Code Preview. Generate a downloadable .md file.
 
Use:
- Markdown headings
- Markdown tables (not code fences)
- Bold totals and key numbers
- Bullet points for recommendations
- No HTML unless needed for styling
